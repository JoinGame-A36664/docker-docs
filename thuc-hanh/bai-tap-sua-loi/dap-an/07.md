# Đề số 7: Trang mở được nhưng báo lỗi

## Gợi ý 1
Trang mở được nhưng có khung đỏ. Đọc kỹ nội dung khung: nó ghi tên máy mà web đang cố gọi.

## Gợi ý 2
Web tìm cuốn sổ ở một cái tên lấy từ biến môi trường. Biến nào? Xem phần `environment` của dịch vụ `web`.

## Gợi ý 3
Giá trị `REDIS_HOST` phải trùng **tên dịch vụ** redis trong `compose.yaml`. Kiểm tra bằng `docker compose exec web env | grep REDIS`.

## Đáp án
**Nguyên nhân:** `REDIS_HOST` bị đổi thành `redis-db`, một cái tên không tồn tại trong mạng. Web gọi tên đó, Docker không phân giải được nên lỗi. (Web vẫn "khỏe" vì đường `/health` của nó không bắt buộc Redis phải sống.)

**Cách phát hiện:**
```sh
docker compose ps                  # tất cả đều healthy, dễ đánh lừa
docker compose logs web            # hoặc đọc khung đỏ trên trang
docker compose exec web env | grep REDIS
```

**Cách sửa:** đặt `REDIS_HOST: redis` (đúng tên dịch vụ), rồi `docker compose up -d`.

**Bài học:** tên dịch vụ trong Compose chính là tên máy trong mạng nội bộ. Healthy chưa chắc hoạt động đúng: trạng thái khỏe chỉ phản ánh điều healthcheck kiểm tra.
