# Đề số 11: Đóng gói image bị lỗi

## Gợi ý 1
Lỗi xảy ra lúc **đóng gói** image của web, ở một dòng `COPY`. Đọc tên file mà nó báo không tìm thấy.

## Gợi ý 2
So tên file trong thông báo với tên file thật trong thư mục `ung-dung` (dùng `ls ../ung-dung`).

## Gợi ý 3
Tên file trong dòng `COPY` của Dockerfile thiếu một chữ cái.

## Đáp án
**Nguyên nhân:** Dockerfile ghi `COPY requirement.txt .` (thiếu chữ `s`) trong khi file thật tên `requirements.txt`. Docker không tìm thấy file nguồn nên bước build thất bại (thông báo dạng *not found* / *failed to calculate checksum*).

**Cách phát hiện:**
```sh
docker compose up -d --build       # lỗi ở bước COPY
ls ../ung-dung                     # tên file thật
```

**Cách sửa:** sửa lại thành `COPY requirements.txt .`, rồi `docker compose up -d --build`.

**Bài học:** nguồn của `COPY` được tính từ thư mục build (context) và phải **trùng chính xác** tên file. Đọc lỗi build từ dưới lên: dòng cuối thường nói đúng bước nào hỏng.
