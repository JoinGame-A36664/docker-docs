# Đề số 5: Chạy khỏe nhưng không ở chỗ bạn nghĩ

## Gợi ý 1
Hệ thống chạy khỏe, chỉ là bạn mở sai chỗ. Hãy xem nginx đang mở cổng nào của máy bằng `docker compose ps`.

## Gợi ý 2
Cổng đó lấy từ biến `HTTP_PORT`. Ai cung cấp giá trị cho biến này? Gợi ý: file nằm cạnh `compose.yaml`.

## Gợi ý 3
Mở file `.env` và đọc thật chậm từng chữ của tên biến. Dùng `docker compose config` để xem giá trị mà Compose thực sự thay vào.

## Đáp án
**Nguyên nhân:** trong `.env` tên biến bị gõ sai thành `HTTP_PROT`. Compose không thấy `HTTP_PORT` nên dùng giá trị mặc định `8080` (phần sau `:-` trong `${HTTP_PORT:-8080}`), và trang mở ở cổng 8080 chứ không phải 8090.

**Cách phát hiện:**
```sh
docker compose ps                          # PORTS của nginx: 0.0.0.0:8080->80
docker compose config | grep -n published  # cổng thật mà Compose dùng
cat .env
```

**Cách sửa:** đổi `HTTP_PROT=8090` thành `HTTP_PORT=8090`, rồi `docker compose up -d`.

**Bài học:** giá trị mặc định `${BIEN:-mac_dinh}` rất tiện nhưng **che giấu lỗi chính tả**. Dùng `docker compose config` để xem giá trị cuối cùng. Với biến bắt buộc, viết `${BIEN:?thông báo}` để Compose báo lỗi thay vì lặng lẽ dùng mặc định.
