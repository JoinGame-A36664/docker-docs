# Đề số 6: Compose báo file không hợp lệ

## Gợi ý 1
Compose kiểm tra file trước khi chạy và từ chối. Đọc xem nó nói thứ gì "chưa được định nghĩa".

## Gợi ý 2
Thông báo nhắc tới volume `du-lieu-redis`. Một volume dùng trong dịch vụ thì phải được khai báo ở đâu đó trong file.

## Gợi ý 3
Ở cuối file `compose.yaml` thiếu khối `volumes:` cấp cao nhất (sát lề trái).

## Đáp án
**Nguyên nhân:** dịch vụ `redis` dùng volume `du-lieu-redis`, nhưng khối khai báo `volumes:` ở cuối file đã bị xóa, nên Compose báo `refers to undefined volume`.

**Cách phát hiện:**
```sh
docker compose config              # service "redis" refers to undefined volume du-lieu-redis
```

**Cách sửa:** thêm lại ở cuối file (sát lề trái):
```yaml
volumes:
  du-lieu-redis:
```
rồi `docker compose up -d`.

**Bài học:** volume và network cũng như vậy: dùng trong dịch vụ thì phải khai báo ở cấp cao nhất của file.
