# Volume và dữ liệu

Container là thứ tạm thời, xóa đi là mất. Muốn giữ dữ liệu phải đặt nó **bên ngoài** container. Thư mục này nói về volume, bind mount, tmpfs và sao lưu.

2. [docker-thuchanh-volume.md](docker-thuchanh-volume.md): Thực hành với volume
3. [docker-coban-backup-and-recovery-containers.md](docker-coban-backup-and-recovery-containers.md): Sao lưu và khôi phục container
